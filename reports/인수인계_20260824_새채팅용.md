## 4. 이번 세션에서 확정한 것

### 4-1. 지표 표준 정의 (확정)

```
1. 정답 스팬과 예측 스팬이 1자 이상 겹치고 라벨이 같으면 후보
2. 겹친 문자 수 내림차순으로 1:1 그리디 배정
   동점 시 (doc_id, gold.start, pred.start) 오름차순
3. TP = 배정된 쌍의 수  ← 분자 하나
   FN = 미배정 정답 / FP = 미배정 예측
   Recall = TP/(TP+FN)   Precision = TP/(TP+FP)
```

SemEval-2013 Task 9.1 · MUC-5 계열의 **partial 기준**. strict(완전일치+라벨) 을 하한으로 병기.
정밀도 바로 아래에 **과잉 마스킹 문자 수**를 항상 병기 (겹침 기준이 경계 과확장을 정답 처리하므로).

**왜 분자가 달랐나** — 정답:예측이 1:1이 아니었기 때문. 두 경우가 실제 존재:

```
경우 ① 예측이 정답 하나를 둘로 쪼갬
  정답 [충청북도 청주시 흥덕구 디지털로 133] / 예측 [충청북도 청주시][흥덕구 디지털로 133]
  → 옛 재현율 0 (정답 전체 담은 예측 없음) / 옛 정밀도 2 (예측 둘 다 정답 안)
경우 ② 예측 하나가 정답 둘을 덮음
  정답 [김소율] 수석([SOYUL KIM]) / 예측 [김소율 수석(SOYUL KIM)]
  → 옛 재현율 2 / 옛 정밀도 0 (예측이 정답 밖으로 넘침)
```

구 정의 코드 위치: `standalone_metrics.py` 411행 `rtp = any(ps<=gs and ge<=pe)` / 468행 `ptp = any(gs<=ps and pe<=ge)`. 둘 다 `any()`라 1:1 제약 없음.

### 4-2. 측정 단위 통일 (확정)

| 층위 | 단위 | 용도 |
| --- | --- | --- |
| **정본** | **스팬** (문자 오프셋 [start,end)) | P·R·F1·F2, 항목별 표 전부 |
| 보조 | 문서 | 경영 보고 — 문서 3,000건 중 몇 건이 새는가 |
| 보조 | 문자 | 노출량 · 과잉 마스킹 |
| 참고 | 토큰 | OPF 모델카드 대조 시에만 |

**스팬을 정본으로 삼는 근거**: ① 정규식(규칙 레이어)은 문자 오프셋만 내므로 토큰 단위로 계측 불가 — 3단 레이어에서 두 레이어를 같은 자로 재려면 스팬뿐 ② 컴플라이언스 "식별자 제거율 99.9%"가 식별자 1건 단위 ③ 정본 라벨이 이미 문자 오프셋 ④ MUC-5/SemEval-13/CoNLL 계열 기본 단위가 엔티티(=스팬), OPF 평가 논문도 span-level 정본 ⑤ 표본검수 시트도 스팬 단위.
※ "청크(chunk)"는 연속된 동일 라벨 토큰 묶음 = 사실상 스팬. 독립 단위 아님.
